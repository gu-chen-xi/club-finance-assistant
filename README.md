# 社团财务报账助手（Club Finance Assistant）

> ⚠️ **停更说明**：本项目已停止更新维护。软件内置的报账步骤、材料要求、命名规则等均属学校管理"流程"，可能随年份/届别调整，本软件**不再跟进此类流程变更**。使用时请以学校及社管部门的最新通知为准，自行核对流程要求。
>
> 🔧 若学校流程有变、需要自行修改代码，见 [流程调整指南](开发期使用的东西/流程调整指南.md)（流程规则 → 代码位置的对照表）。

> 面向高校社团财务的本地桌面端报账管理软件：把"活动报账"从材料整理到归档的整个流程流水线化——活动材料上传 → 实时体检 → 一键生成规范报账包 → 电子/纸质审核跟踪 → 归档入总账。
>
> 本项目为**真实投入使用**的软件（非课程 demo）：由高校学生为所在社团财务部开发，用于日常活动报账，已迭代多个版本，文档驱动、git 分批提交。

## ✨ 功能特性

- **10 步报账流水线**：活动策划 → 采购清单 → 发票 → 凭证 → 领取表/验收单 → 非公务卡 → 生成电子包 → 电子审核 → 纸质提交 → 归档，逐步引导，每步可保存、可中断续做，步骤条支持点击跳转
- **实时"报账体检"面板**：自动检查材料是否齐全、金额是否匹配（发票 vs 凭证 ±0.1 元容差，支持满减/立减等微小差额）、验收单是否确认签字，红项阻断 / 黄项提醒
- **一键生成规范报账包**：按学校规则自动建目录、复制重命名文件（如 `3张发票50元/`、`纸质验收单1.jpg`、`电子验收单.docx`），输出位置每次手动选择
- **模板库**：支持添加自定义模板（pdf / doc/docx / xlsx），可打开、导出到桌面、删除
- **审核与归档**：电子审核状态流转（待提交/已提交/审核中/退回）、纸质提交确认、归档后自动计入总账与余额
- **总账与跟踪**：全部活动收支总览、报销进度看板
- **小彩蛋**：余额低于 50 元红闪提醒拉赞助，余额归零放全屏烟花庆祝

## 🛠 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 桌面外壳 | **Tauri 2.x** | Rust 内核 + WebView2，产物轻量，免装运行时 |
| 前端框架 | **Vue 3 + Vite + TypeScript** | `<script setup>` 组合式 API |
| 样式 | **TailwindCSS** | 原子类 |
| 路由 | **Vue Router**（hash 模式） | 本地单机应用，无需后端 |
| 本地数据库 | **SQLite**（`tauri-plugin-sql`） | 单文件 `app.db`，版本化 migrations 迁移 |
| 文件存储 | 素材文件存原位置，DB 只存路径 | 大文件不入库 |
| 原生能力 | Tauri command | 文件对话框、目录创建、文件复制 |

## 🚀 快速开始（开发）

**环境要求（开发机装一次）**
- Windows 10/11 64 位
- Node.js 20 LTS（含 npm）
- Rust 稳定版工具链（rustup 安装；首次按 Tauri 官方指引装 VS Build Tools）

**命令**

```powershell
npm install          # 安装依赖（首次）
npm run tauri dev    # 开发模式（热更新，自动开窗口）
npm run build        # 类型检查 / 构建前端
npm run tauri build  # 打包产物（exe + MSI），输出在 src-tauri/target/release/
```

## 📖 使用说明（给最终用户）

### 首次使用
1. 打开软件后先去 **设置** 页面填好：社团名称、指导老师姓名、公务卡后四位、学校税号。
2. 初始余额默认为 0，如要手动记录余额可直接在设置里改。

### 报账流程
1. **新建活动**：在"活动报账"页点新建，填活动名和日期。
2. **按 Step1~10 依次填写**：每步有"保存本步"按钮，随时可退出重进，数据不丢。
3. **右侧体检面板**实时显示缺什么/错什么，红项必须解决后再生成电子包。
4. **Step7 生成电子包**：选一个空文件夹，程序自动按学校规则复制重命名文件。
5. **Step8 电子审核**：先交电子版给社管财务部审核，通过后再打印纸质版。
6. **Step9 纸质提交**：纸质版交到社管指定位置，勾选确认。
7. **Step10 归档**：确认无误后归档，自动计入总账。

### 数据与文件保存位置一览

| 内容 | 默认保存位置 | 说明 |
|---|---|---|
| **数据库（含全部业务数据）** | `%APPDATA%\com.clubfinance.assistant\app.db` | 活动、发票、凭证、设置等全部数据都在这一个文件里；备份这一个文件 = 备份全部数据 |
| 模板"导出到桌面" | 用户桌面（Desktop） | 点"导出到桌面"时把模板复制一份到桌面，方便填写后打印 |
| 自定义模板 | 自动**复制**到软件数据目录下的 `custom_templates\` | 添加模板时软件会把文件复制进来 |
| 上传的素材文件（策划书 / 发票 / 凭证 / 领取表 / 验收单 / 审批表等） | **保留在上传时的原位置！软件不会自动创建专门文件夹保存，更不会保存进项目文件夹！** | 除非你自己建文件夹存放素材；否则数据库只存原路径，移动或删除原文件会导致电子包生成时找不到素材 |
| **Step7 生成的电子包** | **无默认地址！每次手动选择输出文件夹** | 生成结果形如 `<社团名>打给<老师><总金额>元/`，所选路径会记录到活动数据中 |
| 打包安装包 | `src-tauri/target/release/` | 仅打包时产生，日常使用不涉及 |

> ⚠️ **重点提醒**：**Step7「生成电子包」没有默认保存地址**，每次都要在弹窗中手动选择一个文件夹作为输出位置，软件不会自动写入任何固定目录。

### 绿色版（便携版）使用说明

- 绿色版 = 一个 exe 文件。
- **务必先把 exe 复制到电脑本地（桌面 / D 盘等）再双击运行，不要从 U 盘直接运行！**
- 原因：程序从 U 盘运行时，Windows 及安全软件会对 U 盘卷留下"隐形占用"，关闭软件后 **U 盘会一直弹不出来**，只能重启电脑才能解除。
- 绿色版与开发版共用同一个数据库（`%APPDATA%\com.clubfinance.assistant\app.db`），换电脑运行会在新电脑上**自动重新创建空数据库**（新一届财务首次使用为空白状态，属正常）。

### 常见问题

- 发票支持 jpg/pdf，png 请先转成 jpg；凭证支持 jpg/png；验收单支持 jpg/docx/xlsx。
- **金额单位**：界面显示元，数据库存分，自动换算。
- **文件路径**：上传的文件保留在原位置，不要随意移动/删除，否则电子包里会找不到。
- **非公务卡**：不适用就选"不适用"跳过，不影响流程。
- **余额低于 50 元**会闪红提醒，记得拉赞助；归零有烟花彩蛋。

## 🧭 页面一览

侧边栏：工作台 / 活动报账 / 总账 / 报销跟踪 / 模板库 / 设置 / 关于；侧边栏底部实时显示当前余额。

- **工作台**：余额、本月支出（标注当前月份）、待报销活动、进行中的活动快捷入口；余额三态彩蛋
- **活动报账**：活动列表 + 10 步流水线（步骤条可点击跳转）+ 右侧实时体检
- **总账**：已归档活动收支总览，每个活动可删除（防点错）
- **报销跟踪**：各活动审核状态看板
- **模板库**：自定义模板（支持 pdf/doc/docx/xlsx，可打开、导出到桌面、删除）
- **关于**：报账须知（金额规则、电子/纸质流程、验收单要求等）
