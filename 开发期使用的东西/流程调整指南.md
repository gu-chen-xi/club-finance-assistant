# 流程调整指南（学校报账流程变了，代码改哪里）

> 本项目已停更。学校的报账"流程"（步骤、材料要求、命名规则、提交位置等）可能随年份/届别调整。
> 本文档是一份**代码地图**：流程哪里变了，对照下表找到代码位置自行修改。
> 修改者不需要读懂整个项目，只需要会改 TypeScript/Vue 的基本文本和条件判断。

---

## 0. 改代码前的准备

```bash
npm install          # 首次
npm run tauri dev    # 开发模式：改前端代码，窗口里实时热更新，边改边看
```

确认没问题后重新打包：

```bash
npm run tauri build  # 产物：src-tauri/target/release/club-finance-assistant.exe（绿色版）
```

## 2. 改步骤（增删改名、改每步内容）

**步骤条与步骤定义** — `Flow.vue` L18：

```ts
const STEPS = [
  "活动策划", "采购清单", "发票", "凭证", "领取表/验收单",
  "非公务卡", "生成电子包", "电子审核", "纸质提交", "归档"
];
```

- **改名**：直接改数组里的文字。
- **增删步骤**：改数组只是第一步，还要同步三处：
  1. 模板区对应的 `v-if="step === n"` 表单区块（每个步骤一个，照抄现有步骤改）
  2. `saveStep()`（L288）：每个步骤离开时要保存什么，按 case 补
  3. `healthItems`（L366–444）：新步骤要不要进体检，加对应规则

**步骤内表单**：模板区搜 `step === 5` 之类的条件即可定位到该步骤的 UI 块。

## 3. 改体检规则（红项阻断 / 黄项提醒）

`Flow.vue` L366–444 的 `healthItems` 计算属性，每条规则就是一行 `items.push(...)`：

```ts
// 红项（阻断生成电子包）
if (invoices.value.length === 0) items.push({ level: "error", text: "未上传发票", step: 3 });
// 黄项（仅提醒）
if (noAmount.length > 0) items.push({ level: "warning", text: `${noAmount.length} 张发票未填金额`, step: 3 });
```

- **学校新增材料要求**：照抄一行，改判断条件和提示文字；`step` 是体检面板点击跳转的目标步骤。
- **金额容差**：L415/L418 的 `0.1` 元容差写在判断里，改数字即可。

## 4. 改电子包生成规则

`Flow.vue` L171 `generatePackage()`：

- **目录结构 / 文件命名**（如 `3张发票50元/`、`纸质验收单1.jpg`）：函数体内拼路径的字符串，按学校新模板改。
- **红项硬阻断**：L173–177，红项未清零直接 `alert` + `return`。若学校允许带问题生成，把 `return` 去掉（不建议）。
- **文件名清洗**：L181 `sanitize()` 负责剔除 Windows 非法字符，一般不用动。

## 5. 改电子审核流程

- 状态存在活动表的 `review_status` 字段，取值：`pending`（待提交）→ `submitted`（已提交）→ `reviewing`（审核中）→ `approved`（通过）/ `returned`（退回，带退回原因）。
- 状态切换按钮在 `Flow.vue` Step8 区块（模板区搜 `step === 8`）。
- **注意**：软件里的状态只是记录，实际审核动作在线下进行——这是设计如此，别当成 bug。

## 6. 改纸质提交与归档

- **勾选"已交到指定位置"**：`Flow.vue` L712 的 checkbox，写入 `activities.paper_submitted`。
- **守卫**（不勾选不能进 Step10）：`next()` L332、`goTo()` L345 各有一份，两处要同步改。
- **归档条件**：L748 按钮 `:disabled`，要求 `review_status === 'approved'` 且已勾选纸质提交。归档时写入 `actual_cost = 发票总额 − 退款总额`，并计入总账。

## 7. 改设置项、默认值、余额口径

- **默认交表位置等默认值**：`src/api/settings.ts` 的默认值常量。**日常换地点/换老师不需要改代码**，在软件"设置"页里改即可，保存在本机数据库。
- **余额公式**：`src/api/balance.ts`，当前口径 `余额 = 初始余额 − 已归档活动实际支出`。工作台卡片和侧边栏共用这一个变量，改这一处全软件生效。

## 8. 改数据库结构

- 表结构在 `src-tauri/src/lib.rs` 的 migrations 数组里（版本化）。
- **铁律：不要改已发布的 migration**，新需求一律追加一条新版本 migration（加列、加表），否则老用户升级会崩。
- 业务数据全在 `%APPDATA%\com.clubfinance.assistant\app.db`（SQLite，可用 DB Browser 打开查看）。

## 9. 改完的自检清单

1. `npm run tauri dev` 里走一遍完整流程（新建活动 → 走到归档），确认改的步骤/规则生效
2. 体检面板红绿状态符合预期
3. 生成一次电子包，打开生成的文件夹核对目录和文件名
4. `npm run tauri build` 重新打包绿色版 exe
